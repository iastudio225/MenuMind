# AVENIQ Brand Kit

Kit extrait et organisé à partir du Brand Board fourni.

## Contenu
- `logos/` : aperçus recadrés des variations de logo visibles sur la planche.
- `icons/` : aperçus d’icône App, Web App, favicon et iconographie.
- `palette/` : couleurs en JSON, SVG, PNG de swatches et aperçu de palette.
- `docs/design-tokens.css` : tokens CSS de couleur et typographie.
- `docs/typography.md` : notes typographiques.
- `docs/ui-components.md` : composants de référence observés.
- `reference/brand-board-original.png` : planche source.

## Palette
Bleu nuit `#0B1F3B`, Terracotta `#E05638`, Pêche `#FFB894`, Ivoire `#FFF7F2`, Ardoise `#64748B`, Bordure `#E5E7EB`.

## Typographie
Inter — Regular, Medium, Semibold, Bold.

## Limites
Les logos et icônes inclus sont des recadrages d’aperçu issus de la planche raster, pas des fichiers vectoriels ou transparents reconstruits. Les dimensions des recadrages ne garantissent pas les dimensions natives d’export. Utilisez les fichiers source du logo pour une production print ou une utilisation à haute résolution.
